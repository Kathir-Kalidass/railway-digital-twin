# Libre-TrainSim runtime port

The ported Libre-TrainSim runtime lives in `res://Data/` and `res://src/`
because upstream scenes hard-code `res://Data/...` and `res://Resources/...`.
This directory records the licence and provenance for that port; it is not an
editor plugin.

- Upstream: Libre-TrainSim v0.9.beta1 (https://libretrainsim.de)
- Licence: GPL v3. See `LICENSE` and the project `LICENSE`.
- Port log: `docs/porting/lts-port.md`.
